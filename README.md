# SplitCoach

App web del equipo Master: plantel, mejores tiempos, resultados, entrenamientos, videos y mensajes entre entrenador y nadadores.

- Página estática (GitHub Pages) + Supabase (base de datos, inicio de sesión por correo y videos).
- `config.js`: dirección y clave pública del proyecto Supabase.
- `schema.sql`: tablas y permisos; se ejecuta una vez en el SQL Editor de Supabase.
- El entrenador ve y edita todo. Cada nadador entra con el correo guardado en su ficha y ve solo su ficha y su conversación.
